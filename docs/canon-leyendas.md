# Canon Oficial de Leyendas - Ecos de Nicaragua

## Objetivo

Este documento define la versión oficial de cada leyenda utilizada dentro del proyecto Ecos de Nicaragua.

Cuando exista una contradicción entre investigaciones, fichas, trivias, audios, imágenes, regiones o futuras APIs, siempre prevalecerá la información contenida en este documento.

---

# La Mocuana

Nombre oficial:
La Mocuana

Tipo:
Leyenda de tradición oral y aparición sobrenatural.

Ubicación principal oficial:
- Sébaco
- Matagalpa
- La Trinidad
- Estelí

Personaje principal:
La Mocuana

Personajes secundarios:
- El Cacique
- El Español o Forastero

Elementos principales:
- Tesoro oculto
- Cueva
- Traición
- Cabellera larga
- Aparición nocturna

Estado:
CANÓNICO

Notas:
Toda referencia futura debe utilizar Matagalpa, Sébaco, Estelí y La Trinidad como ubicaciones principales de la leyenda.

# Regla General

Toda la documentación futura deberá utilizar este canon para:

- Fichas de leyendas.
- Trivia.
- Narraciones.
- Regiones.
- APIs.
- Base de datos.
- Imágenes.
- Audio.
- Frontend.
- Backend.

Si una investigación contiene múltiples versiones, la versión canónica definida aquí tendrá prioridad para efectos del proyecto.
